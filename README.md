# Tuftbot replication instructions
In this repository you can find the technical documentation necessary to replicate the project Tuftbot, a robotic arm set up for tufting. Project developed during the project LAUDS Factory Open Call02 by Landscape Choreography and Lowpoly 

The project aims to establish an innovative microfactory model combining collaborative robotics with traditional textile craftsmanship to valorize European regional wool varieties which are mainly discarded. Primary objectives include developing a sustainable production system for artistic creation, optimizing robotic tufting for autochthonous wool processing, and creating a replicable model for small-scale textile manufacturing that bridges artisanal quality with automated efficiency. Through the development of robotic tufting technology the goal is to allow the activation of supply chains that can be local, from resource extraction to product retail, in order to keep the value produced within rural context. This model is opposed to global extractive value chains.

During the project LAUDS Open Call 2 Lowpoly and Landscape Choreography collaborated, with the support of SUPSI Fablab, to the development of a pilot for tufting with a robotic arm using local coarse wool. From the beginning the project was focused on optimising the work already developed by Lowpoly on robotufting with the requirements given by working with local coarse wool, and with the objective of designing a system replicable wherever there is access to a robotic arm.
To do so all the technical development was done in parallel at Lowpoly studio in Madrid, using an ABB IRB1200 model and at SUPSI Fablab in Medrisio using a KUKA KR6/16/20-3
In the Lowpoly setup, the robot is relatively small and mounted on a wheeled table. Since there are no significant spatial movement constraints, the robot can be moved around and beyond the studio, allowing the frames to be positioned almost 360° around it. In the SUPSI case, being the Fablab within a University, due to safety requirements also connected to the larger size and weight of the robot, the range of motion of the axes was limited. We therefore adapted the development of the project not only to the requirements given by each specific robot model but also to the restrictions given by the prototyping space.
